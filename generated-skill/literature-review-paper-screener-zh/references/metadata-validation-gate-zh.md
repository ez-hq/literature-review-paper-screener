# 元数据校验门 — V1（本地、权威身份校验）

> 适用范围：独立质检门，位于本地**证据采集**与**交接（handoff）**阶段之间。只校验**书目身份**——绝不触碰检索逻辑、筛选逻辑（CRAAP、主题相关度、阅读角色、优先级）、云端 DAG 或工作簿批处理。全程在本地 Agent 执行（可联网）；云端从不校验元数据。
>
> 核心原则：**摘要正确 ≠ 文献记录正确。** 证据内容与书目身份分开校验。

## 步骤 — 元数据权威校验

在任何文献记录写入单篇交接记录（`handoff_p<record_id>.json`）之前，对照权威来源校验其书目元数据。每条文献记录独立执行本校验。

### 1. 必校元数据字段

在可用时校验：标题、作者、出版年份、期刊/来源、卷、期、页码/文章号、DOI、PMID。

### 2. 来源优先级

只使用权威书目数据库。校验优先级：

1. **PubMed** — 用于 PMID 与生物医学文献元数据
2. **Crossref** — 用于 DOI 与出版物元数据

不要把检索片段、AI 生成的引用、出版商片段或此前收集的元数据当作权威验证。

### 3. 校验规则

对每条记录：

#### DOI 校验

若提供了 DOI：

- 核实 DOI 可解析或在 Crossref 中找到。
- 确认 Crossref 记录指向同一出版物。
- 至少比对：**标题、出版年份、期刊、作者**。

若 DOI 指向不同出版物或无法验证：
`DOI_STATUS = INVALID` — 该 DOI 不得作为已核验元数据使用。

#### PMID 校验

若提供了 PMID：

- 在 PubMed 中核实该 PMID。
- 确认 PubMed 记录指向同一出版物。
- 至少比对：**标题、出版年份、期刊、作者**。

若 PMID 指向不同出版物：
`PMID_STATUS = MISMATCH` — 该 PMID 不得进入最终记录。

### 4. 跨字段一致性检查

文献记录不得混用不同出版物的元数据。以下标识符必须指向同一出版物：标题、DOI、PMID、期刊、出版年份。若任一标识符属于不同出版物：
`METADATA_STATUS = MISMATCH` — 不要猜测哪个字段正确。把记录退回证据采集阶段重新核验。

### 5. 校验结果

每条记录得到三种状态之一：

#### VERIFIED

所有可用标识符指向同一出版物 → 记录可进入交接文件。

#### PARTIALLY VERIFIED

出版物已确认，但一个标识符不可得或无法核验。示例：标题与 PMID 已确认，DOI 不可得 → 记录可进入交接文件，但不可得字段必须显式标记：`DOI = NOT VERIFIED`。不得编造或推断替代值。

#### MISMATCH / INVALID

任一 DOI、PMID 或核心书目字段指向另一出版物 → 记录**不得**进入交接文件。退回重新采集。

### 6. 禁止推断规则

绝不构造、推断或猜测书目元数据。不得：

- 从标题猜测 DOI
- 从相似论文复制 DOI
- 因主题相似而假定 PMID 属于某篇论文
- 把已核验的 PMID 与未核验的期刊引用拼在一起
- 仅凭语义相似性修复元数据

书目身份需要权威来源确认。

### 7. 输出规则

只有 `METADATA_STATUS = VERIFIED` 或 `PARTIALLY VERIFIED` 的记录可进入下一阶段。`MISMATCH` 或 `INVALID` 的记录必须在以下环节之前被拦截：交接文件、云端上传、筛选、最终交付。

## 实施说明（本地 Agent）

1. **执行位置**：证据采集（技能第 5 步）之后、写入每个 `handoff_p<record_id>.json`（第 6 步）之前。每篇唯一候选过一次门。
2. **写入交接记录**：添加 `"metadata_status": "VERIFIED" | "PARTIALLY VERIFIED"`；部分核验的记录显式标记不可核验标识符（如 `"doi": "NOT VERIFIED"`）。
3. **结果台账**：记录每轮（记录ID → 状态 → 核查标识符 → 结果说明），交付总结可说明多少篇过门。
4. **MISMATCH/INVALID 处理**：退回证据采集重新核验该记录，不静默丢弃（可得数据原则）。重验仍无法确认身份的，把冲突值提交所有者决定保留/剔除——绝不猜测。剔除时记录原因。
5. **无 DOI/PMID 的记录**：仍可通过权威标题（+作者+年份）在 Crossref/PubMed 查证确认出版物。若权威库完全查无（如极新预印本、两库均未收录的小众出版物）：不标 VERIFIED；标 `PARTIALLY VERIFIED`、标识符标 `NOT VERIFIED`、保留记录（绝不静默丢弃合格文献），并在台账与交付摘要中标注供所有者知晓。所有者决定优先于单条记录。
6. **校验台账**：每轮记录：记录ID → 状态 → 核查标识符 → 结果说明。交付摘要说明过门、拦截、待所有者决定各多少条。
