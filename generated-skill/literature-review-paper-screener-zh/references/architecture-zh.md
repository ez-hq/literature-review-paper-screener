# 架构（中文版）

## 分层职责

| 层 | 职责 | 联网 |
|---|---|---|
| 本地 Agent | 检索、采集证据、元数据校验门、工作簿准备、结果合并与交付 | ✅ 有互联网 |
| 云端模板（胜算云 v3 中文版） | 逐篇筛选（主题相关度、来源有效性、基础可信度、内容可信度按证据边界、时效性、优先级、阅读角色）+ 构建论文清单与阅读清单 | ❌ 无互联网，只评估收到的证据 |

核心原则：**本地采集证据，云端评估组织证据**。摘要正确 ≠ 文献记录正确——书目身份由本地校验门在云端之前确认。

## 语言模型

- 本地 → 云端交接记录：JSON key 英文（协议），文本值中文。
- 云端输出：JSON key 英文（协议），内容中文；仅保留协议字段英文（六类阅读角色分类名、A/B/C/D 字母、pass/fail、DOI/ISBN/URL、文献标题原文）。
- 交付 Excel：中文列头 + 中文内容。

## 执行模型（逐篇）

N 篇文献 = N 行工作簿 = N 个并行云端任务（每行独立计费 ¥0.70）。本地合并结果为一套论文清单 + 阅读清单。多篇单行会在平台活动超时（实测 20 篇 `StartToClose timeout`）。

## 流水线

检索（宽召回）→ 去重 → 采集证据（单篇记录，中文）→ **元数据校验门**（PubMed/Crossref 权威核验，VERIFIED/PARTIALLY 才放行）→ 工作簿（每行一篇，粘贴）→ 平台与费用确认 → 云端逐篇筛选 → 本地校验（合并）→ 中文 Excel 交付（交付前混排检查）。
