# 文献智筛（中文版）— Literature Review Paper Screener (CN)

> **中文版说明（CN version）**：本版本面向使用中文、通过胜算云（人民币支付）运行的国内用户。
> 海外/英文用户请使用英文版：`literature-review-paper-screener.zip`（同仓库同版本，默认优先）。

## 这是什么

「文献智筛」把一堆文献变成可用的文献综述基础：

- 本地 Agent（可联网、免费）检索文献、采集证据、做元数据权威校验（PubMed/Crossref）；
- 云端（胜算云私有模板，全中文输出）逐篇筛选：证据可用级别（A-D）、主题相关度、来源有效性、基础可信度、内容可信度（遵循证据边界）、时效性、优先级、阅读角色；
- 交付两份**中文** Excel：论文清单（完整筛选池）+ 阅读清单（按优先级与阅读角色组织），另附中文交付摘要。

关键原则：本地采集证据 → 云端评估组织；**摘要正确 ≠ 文献记录正确**，书目身份在云端之前由本地校验门确认。

## 快速开始

1. 安装 loomloom：`loomloom doctor` 报告 `healthy=true`；`loomloom server use shengsuanyun`
2. 阅读 `SKILL.md` 的完整工作流（检索 → 采集 → 元数据校验门 → 逐篇工作簿 → 云端筛选 → 合并交付）
3. 必要脚本：`scripts/validate_results.py`（合并校验）、`scripts/render_excel_zh.py`（中文 Excel 渲染）
